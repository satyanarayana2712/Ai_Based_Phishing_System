# PhishShield AI - Browser Extension

## How to Load in Google Chrome / Brave / Microsoft Edge

1. Open your browser and navigate to:
   - Chrome / Brave: `chrome://extensions/`
   - Microsoft Edge: `edge://extensions/`
2. Enable **Developer mode** (toggle in the top right corner).
3. Click **Load unpacked** (top left).
4. Select the `d:\ai_based Pishing website detection\extension` folder.
5. Pin **PhishShield AI** to your browser toolbar!
6. Make sure your FastAPI backend is running (`uvicorn app.main:app --port 8000`).
7. Open any tab or visit a URL and click the PhishShield shield icon to view the real-time AI risk analysis and badge!
